4b:T417,Run a hygiene audit of this project. Change NOTHING — only read and report.

Go through six zones:
1. File size: show the 10 longest files (path and line count) and flag the ones
   where a single file mixes several responsibilities.
2. Inline styles and scripts: where styles or code live inside HTML/templates.
3. Agent settings (for example .claude/settings.json, .claude/settings.local.json,
   .mcp.json, your agent's config): stale permissions, duplicates, absolute paths,
   keys or tokens in plain text.
4. Rules file (CLAUDE.md / AGENTS.md): length, contradictions, outdated instructions.
5. Memory between sessions: is there a file that lets a new session understand
   what's done and what's left.
6. Hooks: which exist and what each one does; if there are none, say so.

Answer format — a table: zone | finding | file | why it gets in the way | effort (small/medium/large).
If a zone is fine, say so — don't invent problems.
At the end, suggest THREE items that give the most benefit at the lowest risk,
and explain your choice.
