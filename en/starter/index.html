Starter: a course project for any agent

A ready project folder for the whole course: an agent rules file, memory between sessions, a folder for practice results, templates and a hygiene checklist. Works with Claude Code, Codex, Gemini CLI, Antigravity, Hermes and any agent that reads AGENTS.md.

It installs nothing and never writes to your home folder. There are no keys inside. The agent, Node.js and Git come from the installer in the Install lesson.

Download the starter (.zip)

Three steps

  1. 1.Download and unzip

    Unzip the archive where you will work. You can rename the tochka-starter folder.

  2. 2.Open it in your agent

    First turn the folder into a git repository: Codex and Hermes look for the rules file from the repository root. Then start your agent in the folder root; see your agent’s tab for how.

    cd tochka-starter
git init
git add .
git commit -m "course starter"

  3. 3.First command

    Send the prompt below. The agent reads the project rules and memory and asks three questions to fill in AGENTS.md with you.

    Read the project rules file and STATE.md. Tell me what you now know about the project and ask me three questions to fill in AGENTS.md.

What your agent reads at start

Start: In the terminal, go to the folder and run claude. On first launch it asks whether you trust the folder.

Rules file: CLAUDE.md. Its single line @AGENTS.md imports the shared rules file in full. Newer versions read AGENTS.md on their own, but only when there is no CLAUDE.md next to it; the import works in any version.

Session-start hook: Yes: .claude/settings.json runs the session-start hook, so the agent sees STATE.md and TODO.md right away.

Source: Claude Code — memory, AGENTS.md · Claude Code — hooks

Honest limits

  • A hook is a command that runs on your computer. Before approving it, open hooks/session-start.mjs: it only reads two files and prints them. It needs Node.js.
  • The same scheme as in the course lessons: context and rules live in AGENTS.md, CLAUDE.md only imports it. This is what the Claude Code docs recommend, and every agent sees the rule. Personal preferences for all projects go into your agent’s global file (~/.claude/CLAUDE.md), not here.
  • What each agent reads at start comes from its official documentation. Agents change: if yours behaves differently, the first command still asks it to read the files explicitly.
